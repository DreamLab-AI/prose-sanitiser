**MSRV caveat.** No 1.89 toolchain is installed in this container, so nothing
was built against the floor *here*. It is gated in CI: the `msrv` job reads
`rust-version` from `Cargo.toml`, installs exactly that toolchain and compiles
every test binary against it. This receipt carries the claim forward on CI's
authority rather than verifying it locally.

**CI gate.** `.github/workflows/ci.yml` runs fmt, clippy, test and
`cargo doc` under `RUSTDOCFLAGS: -D warnings`, plus `cargo deny` and the MSRV
build. This pass added `--all-features` to the clippy, test, doc and MSRV steps:
without it CI never compiled the six `cfg` blocks behind the optional
`external-verify` feature, so that code could rot unnoticed. Together with
`#![deny(missing_docs)]` in all seven crate roots, the documentation standard is
now enforced by the gate rather than being a state that decays.
